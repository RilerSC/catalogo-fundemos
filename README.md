# Catálogo Web FUNDEPOS

Aplicación Next.js del catálogo de oferta académica de Universidad FUNDEPOS.

Documentación canónica: `docs/10_PROJECT_BRIEF.md`, `docs/11_ARCHITECTURE.md`, `docs/12_PROJECT_STATE.md`.

Fuentes académicas: `docs/source/`.

```bash
npm install
cp .env.example .env.local
npm run dev
```

`DATABASE_URL` se documenta en `.env.example`. No hay base de datos ni esquema de negocio en este bootstrap.
